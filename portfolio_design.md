You are a senior product designer, creative frontend engineer,
UX/UI specialist, motion designer, typography specialist, and
digital portfolio art director.

Your task is to design and build my personal portfolio website from ZERO.

This is NOT a generic developer portfolio.

The goal is to create a memorable, elegant, minimal and highly polished
digital experience that represents ONE person through THREE professional
domains:

1. DEVELOPMENT
2. TELECOM / FTTH
3. IT

The website should feel like a premium personal digital experience,
not a résumé pasted into a webpage.

============================================================
                    CORE CREATIVE CONCEPT
============================================================

The central concept is:

ONE PERSON.
THREE PROFESSIONAL DIMENSIONS.

The visitor explores three versions of the same professional identity:

DEVELOPMENT
TELECOM / FTTH
IT

The website itself TRANSFORMS when the active domain changes.

The domain is NOT selected from the header.

The domain changer belongs directly inside the HERO.

The visitor should immediately understand that other professional
domains exist.

The domain selector should therefore remain visible around the hero,
rather than being hidden.

The experience can automatically rotate between the three domains.

The website should feel like:

"Discover another side of what I do."

rather than:

"Select another page."

============================================================
                 COLOR IMPLEMENTATION RULE
============================================================

The three colors are NOT merely small accent colors.

They should influence the overall visual atmosphere of the active domain.

When switching:

DEVELOPMENT → TELECOM

the visual environment should transition:

#E5E5E5 → #BBDEFB

When switching:

TELECOM → IT

the visual environment should transition:

#BBDEFB → #B2DFDB

When switching:

IT → DEVELOPMENT

the visual environment should transition:

#B2DFDB → #E5E5E5

Use smooth interpolation/transitions rather than instant color replacement.

However:

DO NOT color every element with the domain color.

The domain color should act as the ENVIRONMENT and visual identity.

Use neutral colors for:

- body text
- secondary text
- navigation
- structural UI
- borders
- controls

This prevents the portfolio from becoming visually overwhelming.

============================================================
                       DARK MODE
============================================================

Dark mode must be designed intentionally.

Do NOT simply invert the page.

The three domain identities must remain recognizable in dark mode.

Use darker derived backgrounds while preserving the visual relationship
with the original colors.

For example:

Development:
dark neutral derived from #E5E5E5

Telecom:
dark blue derived from #BBDEFB

IT:
dark teal derived from #B2DFDB

The exact derived values can be chosen intelligently.

The original colors remain the source of the domain identity.

Maintain accessibility and contrast.

============================================================
                    AUTOMATIC ROTATION
============================================================

The hero/domain experience should automatically rotate.

Suggested timing:

6–8 seconds.

The user must have enough time to read.

When the user manually interacts:

- immediately switch domain
- reset the timer
- temporarily pause automatic rotation
- allow the visitor to explore

Consider pausing automatic rotation while:

- hovering
- focusing with keyboard
- interacting with the hero

Respect:

prefers-reduced-motion

Users who prefer reduced motion should receive a calmer transition
or no automatic animation.

============================================================
                  DOMAIN TRANSITION
============================================================

The transition between domains is the signature interaction
of the entire portfolio.

When changing domain:

1. Current content transitions out.
2. Domain environment changes.
3. Portrait background transitions.
4. Domain typography changes.
5. Hero statement changes.
6. Skills change.
7. Lower content changes.
8. New content enters.

Example:

DEVELOPMENT
#E5E5E5

becomes

TELECOM
#BBDEFB

The transition should feel like one continuous transformation.

Use approximately:

500–900ms

depending on the element.

Use sophisticated easing.

Avoid:

- bounce
- excessive zoom
- aggressive rotation
- spinning
- dramatic page transitions

The animation should feel premium and intentional.
